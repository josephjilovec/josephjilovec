# Content Model

## Stage vocabulary

### Concept designed
The offer, experience, workflow, and proposed business logic are mapped. It does not imply repeat customers, audited economics, or product-market fit.

### Prototype
A software or interaction demonstration exists. Prototype behavior and illustrative models do not automatically support production-performance claims.

### Active brand
A public brand or business presence is operating. The label does not independently prove revenue, scale, regulatory status, product-market fit, or any specific performance claim.

### Creative project
A public body of creative work exists. It is not evaluated using venture-traction language unless a commercial business is separately demonstrated.

## Project fields

Every venture entry contains:

- name
- category
- stage
- status
- concise summary
- problem / creative territory
- thesis
- current state
- founder role
- next milestone
- opportunity / collaborator need
- external link when available
- external project website when available
- internal project-file route for context and stage disclosure
- visual treatment

## Content rule

The most important sentence on a project page is often **“What exists now?”**. Future revisions should preserve that discipline.
