# Portfolio Architecture

The public Joseph Jilovec Venture Studio portfolio is organized on two dimensions.

## Maturity tiers

- Flagship Assets - institutional-facing operating/advisory assets where the public story should emphasize operating architecture, evidence, and partner readiness.
- Active Validations - ventures with a live public build, pilot, or market-validation loop.
- Incubation Concepts - earlier public concepts where the main purpose is to document the thesis, territory, and next experiment.

## Lifecycle

Every public venture carries one canonical current lifecycle value: IDENTIFY, DESIGN, TEST, or BUILD.

The lifecycle is the public milestone state. Legacy free-form stage labels are retained only as a compatibility field and are normalized to the canonical lifecycle for display.

## Public / private boundary

Public project files describe the problem, thesis, current state, founder role, and next milestone. Detailed capitalization models, valuation assumptions, financing scenarios, and other sensitive diligence documents are not public routes.

Selected ventures may publish an executive one-pager. The one-pager is deliberately high-level and does not include private financing assumptions.

## Navigation model

The portfolio is grouped by maturity rather than presented as one undifferentiated company list. On mobile, venture selectors stack vertically; there is no touch-locked horizontal project rail.
