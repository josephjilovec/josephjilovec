# Brand System

## Parent idea

**Joseph Jilovec** is the parent identity. **Joseph Jilovec Venture Studio** is the organizing system that makes a multidisciplinary portfolio legible.

The design avoids forcing all projects into a single startup aesthetic. The parent brand supplies typography, spacing, navigation, evidence language, stage labels, and a restrained dark environment. Each project introduces one accent color and its own art direction.

## Core visual language

- Base: near-black / deep charcoal
- Type: warm white + cool gray hierarchy
- Signal accent: electric cyan
- Materials: glass-like information panels, fine hairlines, soft optical glow
- Geometry: circles, orbital systems, grids, project graphs
- Editorial behavior: oversized headlines, strong whitespace, short evidence blocks
- Motion: slow, informative, and disabled/reduced when the visitor requests reduced motion

## Project accents

- My Healthy Aura — mint / sea-glass
- Swift Deal Solutions — muted gold
- DJ Hotwax — ember orange
- Vanta Helix — ultraviolet
- CannaCore Seeds / JJ Stash — botanical green
- Snark Logic — hot magenta
- Alder & Meridian — steel blue + warm wood

## Tone

Use direct, concrete language. Avoid inflated founder mythology. Claims should answer: what exists, what is proposed, what has been tested, and what happens next.

## Photography

Founder photography should feel editorial and credible rather than staged as a tech celebrity. The current approved founder portrait is carried into this build as `public/images/joseph-founder.png`.

## Project imagery

Prefer actual product/site screenshots, interface details, diagrams, music artwork, and prototypes. Avoid random stock photography. Until approved assets exist, use the included abstract project art and replace according to the asset map.
