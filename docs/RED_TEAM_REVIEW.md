# Red-Team Review

## Investor

**Question:** Does the site distinguish an investable operating company from a thesis or prototype?

**Revision applied:** Every project has a stage, current-state paragraph, next milestone, and project-stage disclosure. Prototype sites are not treated as proof of commercialization.

## Recruiter

**Question:** Can a visitor understand Joseph's capabilities outside startup language?

**Revision applied:** Founder content is organized around commercial operations, behavioral design, systems/product logic, and creative direction. Operating evidence is separated from venture concepts.

## Journalist / PR

**Question:** Can future-facing product copy be mistaken for verified achievements?

**Revision applied:** Vanta Helix is explicitly described as a concept experience; its specifications, testimonials, launch language, and release framing are not repeated as verified facts. Snark Logic's deterministic demo and illustrative model are likewise labeled as prototype material.

## Developer

**Question:** Is the project maintainable?

**Revision applied:** Venture content is centralized in `lib/ventures.ts`; project pages are generated by slug; client components are limited to interactions; server mail lives in route handlers; docs explain the boundaries.

## Designer

**Question:** Does a parent visual system allow distinct venture identities?

**Revision applied:** The parent brand uses a restrained dark editorial system while each project gets a specific accent and artwork. DJ Hotwax receives a visually different creative treatment rather than a software card template.

## Mobile visitor

**Question:** Do dense portfolio interfaces collapse naturally?

**Revision applied:** Navigation becomes a menu below 900px; constellation/detail stack; venture grids, studio loop, timelines, project-file grids, and contact layouts collapse at defined breakpoints. A reduced 640px breakpoint handles small phones.

## Security engineer

**Question:** Are secrets or unsafe mail behaviors exposed?

**Revision applied:** No private API credentials are present in browser code. Resend is called server-side. Reply-To uses the submitter address. Input length is bounded and a honeypot is included. Durable rate limiting / Turnstile is documented as the next production hardening step if traffic warrants it.

## Accessibility reviewer

**Question:** Can a keyboard/reduced-motion user navigate the experience?

**Revision applied:** Semantic buttons are used for interactive controls; focus states are visible; a skip link is present; forms use labels; status output is announced with `aria-live`; reduced-motion CSS disables ornamental animation.

## PR manager

**Question:** Is any claim unnecessarily aggressive or reputationally fragile?

**Revision applied:** The copy prioritizes "what exists now" over superlatives. Approximate historical revenue is labeled unaudited gross revenue and explicitly not profit, valuation, or current revenue.
